# v21 Learning Engine Report

## Goal

Move Deutsch-WiPA from a flashcard shell toward a learning trainer for B1/B2 German.

## Implemented

1. Smart 10-minute mixed session.
2. Due-review selection from local review state.
3. Weakness diagnosis from recent mistakes.
4. Fuzzy and partial scoring for active German sentence production.
5. Progressive hints before answer reveal.
6. New situation-based production module.
7. Export/import now includes review state.

## Still not solved

- No real speech recognition.
- No teacher-grade correction of free writing.
- No listening comprehension module yet.
- No certified CEFR placement test yet.
- No server sync; progress is local-only.

## Next target

v22 should add structured writing correction rubrics and speaking/shadowing tasks, not random new vocabulary.
