# Deutsch-WiPA 2026 v13 — Translation and Resources

## Added

- A translation button (`🌐`) on every exercise card.
- The translation helper first uses stored item translations when available.
- If no stored translation exists, it provides external translation links for the current German prompt/example.
- Translation target follows the selected interface language. If the interface is German, English is used as fallback.
- External resource panel in the right learning panel.

## Resource links

- Dreizunge — Raim's app: https://raim.github.io/dreizunge/#
- DW Learn German: https://learngerman.dw.com/
- Verbformen: https://www.verbformen.de/
- LEO dictionary: https://dict.leo.org/german-english/
- Lingolia German grammar: https://deutsch.lingolia.com/en/
- Duden: https://www.duden.de/
- Reverso German conjugator: https://conjugator.reverso.net/conjugation-german.html
- Goethe exercises: https://www.goethe.de/en/spr/ueb.html

## Static-app limitation

This is not a live translation API. The app remains GitHub Pages-compatible and does not send data to a custom backend. External links open in a new tab when the user explicitly chooses them.
