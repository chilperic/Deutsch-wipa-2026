# Deutsch-WiPA 2026 — Modern Grammar Build

Modern B1/B2 German trainer focused on grammar, conjugation and workplace vocabulary.

## What changed

- Full UI redesign: cleaner top navigation, learner-facing path, large exercise cards.
- Removed active writing/reading/speaking emphasis.
- Reorganized themes: Konjugation, Satzbau, Fälle, Präpositionen, Artikel & Nomen, Adjektive, Konnektoren, Wortschatz Beruf.
- Added a Reverso-style **Konjugator** section with verb tables.
- Added a large conjugation drill database for Präsens, Präteritum, Perfekt, Plusquamperfekt, Futur I and Konjunktiv II.
- Added explanations and sentence variation practice for B1/B2 grammar.
- Improved PWA assets and mobile layout.

## Run locally

```bash
npm run check
npm run start
```

Open `http://localhost:8080`.
